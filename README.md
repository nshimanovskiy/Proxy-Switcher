# Proxy-Switcher
Easy-to-use HTTP and SOCKS proxy switcher with support for multiple proxy servers, authentication, and quick switching between configurations.

Proxy Switcher is a convenient Firefox extension for managing HTTP, HTTPS, SOCKS4, and SOCKS5 proxy servers with authentication support.

Key Features:
• Quick proxy setup via URL or manual configuration
• Support for HTTP, HTTPS, SOCKS4, and SOCKS5 protocols
• Username/password authentication
• Save multiple proxy configurations
• Fast switching between saved proxies
• Auto-connect to last used server
• Clean and intuitive interface

Supported Formats:
• URL format: http://host:port, socks5://user:pass@host:port
• Simple format: host:port, type:host:port:username:password

Perfect for users who need to frequently switch between different proxy servers for privacy, testing, or accessing region-restricted content.
